# Bashar Shop — GitHub APK Build

1. Upload all project files to a GitHub repository.
2. Put your Firebase `google-services.json` inside `app/`.
3. Open GitHub → Actions → **Build Bashar Shop APK** → **Run workflow**.
4. After the build succeeds, open the run and download **BasharShop-debug-apk** from Artifacts.

This workflow creates a debug APK. A Play Store release needs a signed release APK/AAB.
